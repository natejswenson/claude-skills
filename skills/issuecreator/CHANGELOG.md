# Changelog

All notable changes to the **issuecreator** skill are documented here.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and
this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-09-12

### Added

- Repository-grounded GitHub issue drafting for issueflow, shared by Claude Code and Codex.
- Structured validation and Markdown rendering with scope, acceptance criteria and verification.
- Authorized publication with read-back verification and durable protection against uncertain retries.
- Real local draft baseline and offline validation/publication tests.

- Preserve complete draft JSON during rendering, reject ignored evidence fields, and protect publication artifacts from later rendering.
