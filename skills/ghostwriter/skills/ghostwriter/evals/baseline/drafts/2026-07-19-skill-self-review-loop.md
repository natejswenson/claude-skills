I improve my Claude skills the same way: I periodically ask Fable to review their previous runs.

The review covers four dimensions:

- Accuracy: did it do what the skill promises?
- Completeness: what did it miss?
- Efficiency: where did it waste tokens or time?
- Agent UX: where did the skill fight the agent?

The findings turn into concrete changes, and the changes ship as the next version of the skill. Every round of this has made the skill measurably better at its job.
