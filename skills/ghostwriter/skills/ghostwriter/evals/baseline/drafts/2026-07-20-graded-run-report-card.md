My running agent gave a run a C for being too fast, and that letter was never the model's call.

The grades are deterministic. Four metrics, each reduced to a single number, all run through the same table in Python. Easy days are supposed to be easy, so 60 seconds per mile fast costs you, every time.

The write-up isn't. The model gets the finished grades, the coach persona I'd already written, and context from the same data its other tools manage: my last two weeks of runs, and the next seven days of planned workouts. So the read knows Tuesday is intervals, and warns the fast easy day already put it at risk.

The context shapes the sentences. It never moves a letter.

Anything a number can settle, I settle before the model sees it.
