# Changelog

All notable changes to the **local-dev** skill are documented here.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and

## [0.1.0] - 2026-09-23

### Added

- Terminal workflow for typed features, selected GitHub issues, and local resume.
- Clarification, independent plan red team, separate plan commit, implementation,
  local tests and review, implementation commit, and final draft PR delivery.
- Read-only Git inspection and explicit issue intake helpers, with an offline
  inspection report and regression baseline.
- Shared Claude Code and Codex packaging, local-only mode, and recovery guidance
  for interrupted or uncertain publication.
